# Krishna Arora: personal site

## Publish on GitHub Pages
1. Create a public repo named `YOUR-USERNAME.github.io`.
2. Add file > Upload files: drop in everything in this folder (index.html, posts.js, images/ and README.md).
3. Settings > Pages > Deploy from branch > `main` / root > Save. Live in about a minute.

## Add a new blog post
Open `posts.js`, copy one block, paste it at the top of the list, and change slug, title, cat, date and body. Commit the change on GitHub and it goes live.
To add photos, upload them to `images/` and use `![caption](images/name.jpg)` in the body.

## Beyond work
Edit the `beyond()` function in index.html when you're ready.
